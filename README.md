## 👋 About Me

I'm **Ferdian Sakti**, an Informatics Engineering graduate and IT professional with **10+ years of experience** across IT infrastructure, networking, system administration, software development, and technology education.

My work sits at the intersection of **reliable IT systems, practical software engineering, and data-driven intelligence**. I enjoy designing and maintaining technology environments, building useful applications, exploring machine learning, and helping learners turn ideas into working solutions.

Currently, I work in programming and AI education, with a focus on helping students develop practical skills in Python, data analytics, data science, and machine learning.

- 🎓 **Education:** B.Eng. in Informatics Engineering — Universitas Hasyim Asy’ari Tebuireng Jombang
- 👨‍🏫 **Current focus:** Programming & AI instruction, Python, and digital literacy
- 🧠 **Areas of interest:** Artificial Intelligence, Machine Learning, Data Science, and NLP
- 🌐 **Engineering background:** Network infrastructure, system administration, and web application development
- 🧑‍💻 **Community:** External Academy Code Reviewer at Dicoding Indonesia
- 📍 **Based in:** Indonesia
